## 评测原则
1. 不自查原则：产出者不查自己，验证由独立方执行
2. 可复放：每份结论附完整步骤与证据
3. 分级：P0-P3 判据谱系，阻断项未修复不得发布
4. 中立：评测方与被评测方无控制性利益关系（关联关系与隔离机制见 CONFLICT_OF_INTEREST_DISCLOSURE.md）

## 评测流程
1. 培训（协议/标准/口径）
2. 独立执行（不采信自查结论）
3. 证据闭环（哈希/时间戳/复放步骤）
4. 独立验收通过方可发布
